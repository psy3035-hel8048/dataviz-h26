# dataviz-h26
Course materials for data visualisation course, høst 2026. This course combines PSY-3035 and HEL-8048.

# Getting started
We will use a number of tools, with Python programming and plotting functions being central. You should have Anaconda installed and your favourite IDE (you should choose Visual Studio Code as default).

# Discussions
The Github Discussions function will be used to address questions or problems with the material and your own code/projects as we progress through the course. The file contributing.md describes the best way to post a new discussion point (especially if it involves your code).

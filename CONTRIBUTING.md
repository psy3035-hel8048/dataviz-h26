# Contributing and Asking for Help

Welcome! This repository is a shared space for course notebooks, examples, resources, and discussion.

Please read these guidelines before opening an Issue, starting a Discussion, or contributing changes.

## Where should I post?

### Use GitHub Discussions for questions

Use **Discussions** for:

- Questions about lecture material, concepts, or notebooks
- Help understanding an error or debugging approach
- Installation and environment setup questions
- Requests for clarification about an assignment
- Sharing useful course-related resources
- General course discussion

Before posting, please search existing Discussions: someone may already have asked and answered the same question.

### Use GitHub Issues for problems with course materials

Use an **Issue** to report a specific problem with the repository, such as:

- A notebook does not run as provided
- A code example contains an error
- A link, dataset, or file is missing
- Instructions are unclear or incorrect
- You have found a reproducible bug in starter code

Please do **not** use Issues for general conceptual questions unless the question identifies an error in the course materials.

## How to ask a good technical question

When asking for help, include enough information for someone else to understand and reproduce the problem.

A helpful post usually includes:

1. **What you are trying to do**
2. **What you expected to happen**
3. **What actually happened**
4. **The full error message**, if there is one
5. **The relevant code**, formatted as a code block
6. **Your environment**, where relevant:
   - operating system
   - Python/R/Julia version
   - package versions
   - whether you are using Jupyter, VS Code, Colab, etc.

For example:

```text
I am trying to run `notebooks/03-regression.ipynb`.

I expected the model-fitting cell to run, but I receive:

ModuleNotFoundError: No module named 'sklearn'

I installed the environment using the instructions in the README.
I am using Python 3.11 on macOS and JupyterLab 4.
